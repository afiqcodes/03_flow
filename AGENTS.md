
## Project Overview

This project is a personal daily-use dashboard built with:

- Flask
- PostgreSQL
- Docker
- Docker Compose
- HTML
- CSS
- JavaScript
- Jinja templates

The app is intended to be a general daily-life productivity application.

Current or planned modules include:

- Tasks
- Logbooks
- Budgets
- Bookmarks
- Subscription Billings

The application should remain simple, modular, clean, and easy to maintain.


## Main Goals

When modifying this project:

- Keep the existing Flask architecture.
- Keep PostgreSQL as the database.
- Keep Docker Compose as the main development environment.
- Avoid introducing unnecessary frameworks.
- Prefer simple solutions over overly complex abstractions.
- Preserve existing functionality when adding new features.
- Keep the interface visually consistent across all modules.
